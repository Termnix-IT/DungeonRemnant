# Dungeon Remnant

Godot製の見下ろし型アクションローグライトです。拠点から章へ出撃し、分岐する層を選びながら押し寄せる敵の群れと戦い、最後の層のボスを目指します。ランの中で強化を重ねて攻撃の形を変え、持ち帰った残響で拠点の永続強化を育てます。全4章で、最終章のボスを初めて倒すとエンディングを迎え、その後は難易度の段階を上げながら遊び続けられます。

> [!IMPORTANT]
> 現在開発中のプロジェクトです。仕様、バランス、グラフィック、セーブデータ形式は今後変更される可能性があります。
> 2026年10月に、ターン制のローグライクからリアルタイムアクションのローグライトへ作り替えました。経緯は[リアルタイム化 再設計計画](./docs/リアルタイム化_再設計計画.md)にあります。

## 実装済みのシステム

- 自由移動・ダッシュ（無敵時間付き）・コンボ攻撃・溜め攻撃と、2つのスキルの枠と必殺技によるリアルタイム戦闘
- 武器3種類（剣・槍・大槌）・スキル6種類・必殺技3種類を、拠点のステータス画面で付け替えて出撃する
- ヒットストップ・ノックバック・ダメージ数字と、敵の攻撃の予兆表示
- 全4章（灰の回廊・風哭きの樹海・紫晶の霊廟・残響の深淵）。章ごとに地形・敵・ボスが替わり、前の章を踏破すると次の章が開く
- 図鑑に載る敵33種類（群れ16・難易度の段階で出る強敵版8・精鋭5・ボス4）と、最大200体規模の同時戦闘。ボスは傷が深くなると第2フェーズに入り、手下を呼ぶ
- 層ごとに2〜3個のエリアから進む先を選ぶ章の分岐マップ。エリアはフィールド（生き延びる・撃破数）・アリーナ（ウェーブ）・ボスの間で、途中に戦闘のないイベント5種類（行商人・血の祭壇・呪いの石碑・記憶の書架・浄めの泉）と呪いがある
- 経験値の宝石とレベルアップ、攻撃の挙動を変える32種類の周回限定強化
- エリアの報酬（強化・回復・残響）と、踏破・敗北・中断の結果画面
- 最終章を初めて踏破すると流れるエンディング（静止画と文、スタッフロール）
- エンディングの後に開く8段階の難易度の段階。出撃画面で選び、段階ごとに制約が1つずつ増える代わりに、持ち帰る残響も増える
- 残響で育てる32節の永続強化ツリー、敵の図鑑、自動セーブ・ロード（旧ターン制版のセーブは残響へ換算して引き継ぐ）
- 音楽と効果音、設定（音量・画面の揺れ・画面モード・操作の案内）とヘルプ
- ゲームパッド操作

## 操作方法

| 操作 | キーボードとマウス | ゲームパッド |
|---|---|---|
| 移動 | `WASD` / 矢印キー | 左スティック / 十字キー |
| 照準 | マウスの位置 | 右スティック |
| 攻撃 | 左クリック（長押しで溜め攻撃） | `X`（長押しで溜め攻撃） |
| 回避 | `Space` | `A` / `RB` |
| スキル1 | `Q` | `Y` |
| スキル2 | `E` | `B` |
| 必殺技（ゲージが満ちたとき） | `R` | `LB` |
| メニュー | `Esc` | `Start` |
| 強化カードの選択 | 数字キー `1`～`4` / クリック | 十字キーと `A` |
| 分岐の選択 | 数字キー `1`～`3` / クリック | 十字キーと `A` |

操作キーは、Godotエディターのプロジェクト設定の「インプットマップ」で変更できます。

## 開発環境

- Engine: Godot 4.7系
- Project root: `rogue-like-play/`
- Main scene: `rogue-like-play/game/main.tscn`
- Target platform: Windows 64-bit

Godot 4.7系で `rogue-like-play/project.godot` を開き、`F5` でプロジェクトを実行します。
