# Dungeon Remnant

Godot製の見下ろし型アクションローグライトです。拠点から章へ出撃し、分岐する層を選びながら押し寄せる敵の群れと戦い、最後の層のボスを目指します。ランの中で強化を重ねて攻撃の形を変え、持ち帰った残響で拠点の永続強化を育てます。

> [!IMPORTANT]
> 現在開発中のプロジェクトです。仕様、バランス、グラフィック、セーブデータ形式は今後変更される可能性があります。
> 2026年10月に、ターン制のローグライクからリアルタイムアクションのローグライトへ作り替えました。経緯は[リアルタイム化 再設計計画](./docs/リアルタイム化_再設計計画.md)にあります。

## 実装済みのシステム

- 自由移動・ダッシュ（無敵時間付き）・3段コンボ・溜め攻撃・範囲スキルによるリアルタイム戦闘
- ヒットストップ・ノックバック・ダメージ数字と、敵の攻撃の予兆表示
- 群れの雑魚2種類、精鋭1種類、2段階のフェーズを持つボス1体と、最大200体規模の同時戦闘
- 3層とボスからなる章の分岐マップと、フィールド（生き延びる・撃破数）とアリーナ（ウェーブ）のエリア
- 経験値の宝石とレベルアップ、攻撃の挙動を変える8種類の周回限定強化
- エリアの報酬（強化・回復・残響）と、踏破・敗北・中断の結果画面
- 残響で育てる永続強化の強化ツリー、敵の図鑑、自動セーブ・ロード（旧ターン制版のセーブは残響へ換算して引き継ぐ）
- ゲームパッド操作

## 操作方法

| 操作 | キーボードとマウス | ゲームパッド |
|---|---|---|
| 移動 | `WASD` / 矢印キー | 左スティック / 十字キー |
| 照準 | マウスの位置 | 右スティック |
| 攻撃 | 左クリック（長押しで溜め攻撃） | `X`（長押しで溜め攻撃） |
| 回避 | `Space` | `A` / `RB` |
| スキル | `Q` | `Y` |
| メニュー | `Esc` | `Start` |
| 強化カードの選択 | 数字キー `1`～`3` / クリック | 十字キーと `A` |
| 分岐の選択 | 数字キー `1`～`3` / クリック | 十字キーと `A` |

操作キーは、Godotエディターのプロジェクト設定の「インプットマップ」で変更できます。

## 開発環境

- Engine: Godot 4.7系
- Project root: `rogue-like-play/`
- Main scene: `rogue-like-play/game/main.tscn`
- Target platform: Windows 64-bit

Godot 4.7系で `rogue-like-play/project.godot` を開き、`F5` でプロジェクトを実行します。
