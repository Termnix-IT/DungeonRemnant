# Dungeon Remnant

Godot製の2Dターン制ローグライクです。拠点で準備を整え、ランダム生成されるダンジョンを探索して、10Fのボス討伐を目指します。

> [!IMPORTANT]
> 現在開発中のプロジェクトです。仕様、バランス、グラフィック、セーブデータ形式は今後変更される可能性があります。

## 実装済みのシステム

- 3種類のマップ構成を組み合わせた、1F～10Fのランダムダンジョン生成
- グリッドベースのターン制移動・攻撃と、視界・遮蔽・探索済み地形を扱うFog of War
- 異なる感知・行動パターンを持つ3種類の通常敵と10Fボス
- 剣・槍・ハンマーの3種類の武器、装備、回復薬、床アイテム
- Inventory、Main / Sub武器切り替え、防具・アクセサリー装備
- EXPとレベルアップ、10種類の冒険中能力
- Gold、拠点、永久強化、死亡・中断時の所持品損失
- 10Fボス討伐によるクリアとリザルト表示
- Gold、永久強化、Inventory、装備の自動セーブ・ロード

## 操作方法

| 操作 | キー |
|---|---|
| 上下左右移動 | `WASD` / 矢印キー / テンキー `2` `4` `6` `8` |
| 斜め移動 | `Q` `E` `Z` `C` / テンキー `7` `9` `1` `3` |
| 攻撃 | `Space` / テンキー `5` で攻撃モード→方向選択→再度押して確定 |
| 攻撃キャンセル | `Esc` |
| 能力選択 | 数字キー `1`～`3` / 画面上のボタン |
| Inventoryの開閉 | `I`（`Esc`でも閉じる） |
| Main / Sub武器切り替え | `Tab` |
| 冒険の中断確認 | `R` |
| リザルトから拠点へ帰還 | `R` / 「拠点へ戻る」ボタン |

壁や敵に向かって移動した場合は向きだけが変わり、ターンは進みません。空振り攻撃は1ターン消費します。

## 開発環境

- Engine: Godot 4.6系
- Main scene: `game/main.tscn`
- Target platform: Windows 64-bit

Godot 4.6系で `project.godot` を開き、`F5` でプロジェクトを実行します。
