# 地形とエフェクトの絵

このファイルは、Codexの組み込み画像生成（gpt-image-2.5）で作った絵の依頼文と、生成の経緯の記録です。同じ種類の絵を作り直す・足すときに、近い絵の依頼文を探して読みます。依頼に共通する決まりと、素材を差し替えるときに一緒に直す箇所は `rogue-like-play/開発メモ.md` にあります。

## 地形の元絵

- 元絵はCodexの組み込み画像生成（gpt-image-2.5）で、当時のドット絵の板（`art/tiles/source/slate.png`）を題材と色、主人公のベース画を塗り、ロビーの背景を石の見え方の参考として渡した。床は「不規則な大きさの青灰のスレートの敷石を、正方形の格子にそろえずに敷いた古い床。均一な明るさで、光の勾配・周辺減光・物は描かない。キャラクターが目立つよう低めのコントラスト」、壁は「厚い壁の上面の、粗く切った暗い青灰の石組み」、柱と階段は透過背景の単体で、今の板と同じ少し上からの視点で依頼した。ほかの画風は、遺跡の4枚を画風の参考、各画風のドット絵の板（`moss.png`・`ember.png`・`sanctum.png`）を題材と色の参考として渡し、同じ指示に画風の色（苔の生えた緑灰の石、熱で細く光る割れ目のある赤褐色の火山岩、金の象嵌が散る紫黒の黒曜石）を加えた。聖域の板は1マスごとに金の枠があるが、床にマス目が出ないよう枠は描かせていない。木はドット絵の4種類（丸い広葉樹・黄緑の差し色・白い花と垂れる蔓・うろのあるねじれた幹）を、透過背景で根を下の中央に置いて描かせた。
- 第2章の樹海（`grove`）は床と壁だけを描いた画風で、階段と柱は苔むした洞窟のものを借りる（ツールの `BORROWS`）。元絵はCodexの組み込み画像生成（gpt-image-2.5）で、`moss_floor.png`・`moss_wall.png`・`forest_tree_a.png` を画風の参考として渡し、床は「落ち葉（くすんだ緑・黄土・赤茶）の散る暗い腐葉土に、小さな苔・細い根・小石。細かく均一で、光の勾配・周辺減光・大きな目立つ物・道・マス目なし。キャラクターが目立つよう低いコントラスト」、壁は「通れない茂みの上面。太く絡み合う根と暗い下草に苔。床よりはっきり暗く粗く、2×2マスに広げても根が読める大きさ」と依頼し、半分ずらして継ぎ目がないことを確かめた。
- 第3章の霊廟（`crypt`）は床と壁だけを描いた画風で、階段と柱は黒曜の聖域のものを借りる（ツールの `BORROWS`）。元絵はCodexの組み込み画像生成（gpt-image-2.5）で、床は `grove_floor.png`・`sanctum_floor.png`、壁は `sanctum_wall.png`・`moss_wall.png` を参考に渡し、床は「大きさのそろわない暗い紫灰の切り石を、正方形の格子にそろえずに敷いた地下の霊廟の床。細いひび、少しの白い骨の粉、ひびの中の小さな紫水晶のかけら。均一な明るさで、光の勾配・周辺減光・大きな目立つ物・道・マス目なし。キャラクターが目立つよう低いコントラスト」、壁は「通れない厚い霊廟の壁の上面。粗い暗い炭色がかった紫の石組みに、ぎざぎざの紫水晶の塊が生える。床よりはっきり暗く粗く、2×2マスに広げても石と結晶が読める大きさ」と依頼した。半分ずらして継ぎ目がないことを確かめたので、`SEAM_FIX` はかけていない。
- 第4章の深淵（`abyss`）も床と壁だけを描いた画風で、階段と柱は黒曜の聖域のものを借りる（ツールの `BORROWS`）。元絵はCodexの組み込み画像生成（gpt-image-2.5）で、床は `crypt_floor.png`・`sanctum_floor.png`、壁は `crypt_wall.png`・`sanctum_wall.png` を参考に渡し、床は「大きさのそろわない黒に近い玄武岩の敷石を、正方形の格子にそろえずに敷いた深淵の床。細いひびのいくつかの奥に、かすかな金の残響の光と少しの細かい金の粉。均一な明るさで、光の勾配・周辺減光・大きな目立つ物・道・マス目なし。キャラクターが目立つよう低いコントラスト（金はかすかに、まばらに）」、壁は「通れない厚い壁の上面。粗い黒い玄武岩の石組みと崩れたゴシックの石材に、ひびを走る明るい金の残響の筋。床よりはっきり暗く粗く、2×2マスに広げても読める大きさ」と依頼した。半分ずらして継ぎ目がないことを確かめたので、`SEAM_FIX` はかけていない。

## エフェクトの元絵

- 元絵はCodexの組み込み画像生成で、番兵と主人公のベース画を画風の参考、従来のドット絵の連番を題材の参考として渡し、「最も強い瞬間の1枚。光は純黒の背景、煙は透過背景。約70pxで読める形」という共通の指示に種類ごとの説明を加えて作った。
- レベルアップの光の柱（`level_up.png`）はあとから足した。斬撃の元絵を画風の参考だけに渡し、「純黒の背景に、足元の楕円の光の輪から立ち上がり上へ細りながら消える金色の光の柱。小さな金と淡いクリーム色の光の粒と、上へ昇る細い光の筋。緑・紫・植物・地面・人物は描かない。周囲に広い黒の余白」と依頼した（治癒の元絵を参考に渡すと葉の形が混ざったため外した）。
