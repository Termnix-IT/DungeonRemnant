# 地形とエフェクトの絵

このファイルは、Codexの組み込み画像生成（gpt-image-2.5）で作った絵の依頼文と、生成の経緯の記録です。同じ種類の絵を作り直す・足すときに、近い絵の依頼文を探して読みます。依頼に共通する決まりと、素材を差し替えるときに一緒に直す箇所は `rogue-like-play/開発メモ.md` にあります。

## 地形の元絵

- 元絵はCodexの組み込み画像生成（gpt-image-2.5）で、当時のドット絵の板（`art/tiles/source/slate.png`）を題材と色、主人公のベース画を塗り、ロビーの背景を石の見え方の参考として渡した。床は「不規則な大きさの青灰のスレートの敷石を、正方形の格子にそろえずに敷いた古い床。均一な明るさで、光の勾配・周辺減光・物は描かない。キャラクターが目立つよう低めのコントラスト」、壁は「厚い壁の上面の、粗く切った暗い青灰の石組み」、柱と階段は透過背景の単体で、今の板と同じ少し上からの視点で依頼した。ほかの画風は、遺跡の4枚を画風の参考、各画風のドット絵の板（`moss.png`・`ember.png`・`sanctum.png`）を題材と色の参考として渡し、同じ指示に画風の色（苔の生えた緑灰の石、熱で細く光る割れ目のある赤褐色の火山岩、金の象嵌が散る紫黒の黒曜石）を加えた。聖域の板は1マスごとに金の枠があるが、床にマス目が出ないよう枠は描かせていない。木はドット絵の4種類（丸い広葉樹・黄緑の差し色・白い花と垂れる蔓・うろのあるねじれた幹）を、透過背景で根を下の中央に置いて描かせた。
- 第2章の樹海（`grove`）は床と壁だけを描いた画風で、階段と柱は苔むした洞窟のものを借りる（ツールの `BORROWS`）。元絵はCodexの組み込み画像生成（gpt-image-2.5）で、`moss_floor.png`・`moss_wall.png`・`forest_tree_a.png` を画風の参考として渡し、床は「落ち葉（くすんだ緑・黄土・赤茶）の散る暗い腐葉土に、小さな苔・細い根・小石。細かく均一で、光の勾配・周辺減光・大きな目立つ物・道・マス目なし。キャラクターが目立つよう低いコントラスト」、壁は「通れない茂みの上面。太く絡み合う根と暗い下草に苔。床よりはっきり暗く粗く、2×2マスに広げても根が読める大きさ」と依頼し、半分ずらして継ぎ目がないことを確かめた。
- 第3章の霊廟（`crypt`）は床と壁だけを描いた画風で、階段と柱は黒曜の聖域のものを借りる（ツールの `BORROWS`）。元絵はCodexの組み込み画像生成（gpt-image-2.5）で、床は `grove_floor.png`・`sanctum_floor.png`、壁は `sanctum_wall.png`・`moss_wall.png` を参考に渡し、床は「大きさのそろわない暗い紫灰の切り石を、正方形の格子にそろえずに敷いた地下の霊廟の床。細いひび、少しの白い骨の粉、ひびの中の小さな紫水晶のかけら。均一な明るさで、光の勾配・周辺減光・大きな目立つ物・道・マス目なし。キャラクターが目立つよう低いコントラスト」、壁は「通れない厚い霊廟の壁の上面。粗い暗い炭色がかった紫の石組みに、ぎざぎざの紫水晶の塊が生える。床よりはっきり暗く粗く、2×2マスに広げても石と結晶が読める大きさ」と依頼した。半分ずらして継ぎ目がないことを確かめたので、`SEAM_FIX` はかけていない。
- 第4章の深淵（`abyss`）も床と壁だけを描いた画風で、階段と柱は黒曜の聖域のものを借りる（ツールの `BORROWS`）。元絵はCodexの組み込み画像生成（gpt-image-2.5）で、床は `crypt_floor.png`・`sanctum_floor.png`、壁は `crypt_wall.png`・`sanctum_wall.png` を参考に渡し、床は「大きさのそろわない黒に近い玄武岩の敷石を、正方形の格子にそろえずに敷いた深淵の床。細いひびのいくつかの奥に、かすかな金の残響の光と少しの細かい金の粉。均一な明るさで、光の勾配・周辺減光・大きな目立つ物・道・マス目なし。キャラクターが目立つよう低いコントラスト（金はかすかに、まばらに）」、壁は「通れない厚い壁の上面。粗い黒い玄武岩の石組みと崩れたゴシックの石材に、ひびを走る明るい金の残響の筋。床よりはっきり暗く粗く、2×2マスに広げても読める大きさ」と依頼した。半分ずらして継ぎ目がないことを確かめたので、`SEAM_FIX` はかけていない。

## 戦場の物・落とし物・かけら・ボスの陣・強化のカード（2026-11-22）

戦闘の画面を作り直したときに、Codexの組み込み画像生成で8枚を作った（`codex exec` を4本ずつ並べて実行。どれも1回目の絵を採用した）。元絵は `art/tiles/painted/source/props_<画風>.png`・`floor_decals.png`、`art/effects/painted/source/echo_shards.png`・`boss_sigil.png`、`art/ui/source/cards.png` にあり、`python tools/build_battle_art.py` が切り分けて縮める。

- どの依頼にも付けた条件。参考として、当時の戦闘の画面（床が平坦で柱が黒い四角に見える状態）、森の木の板（視点と「板に物を横に並べる」形式の見本）、キャラクターの絵（塗りと輪郭の見本）、6つの床、分かれ道の門の画面（そろえたい品質の基準）、かがり火の台・青銅の紋章・金の額縁（金属と石の塗りの見本）を渡した。「厚塗りのイラスト。はっきりした暗い輪郭。形は太く単純。光は左上からの柔らかい光だけで、地面の影・光の筋・発光のにじみ・炎・煙は描かない（ゲーム側で重ねる）。物の外側とすき間はマゼンタ（#FF00FF）で平らに塗る。マゼンタの色むらと数pxの大きさの違いは作り直しの理由にしない」と伝えた。
- 戦場に立つ物（`props_ruin`・`props_ember`・`props_crypt`・`props_abyss`。各1536×1024）。「4つを横1列に、足元を同じ高さ（上から約88%）にそろえ、物と物の間に幅60px以上のマゼンタのすき間。森の木と同じ、少し斜め上から見下ろした視点。どれも足元に低い石の台がある。ゲームでは高さ120〜200pxに縮めて使う」。遺跡は折れた石柱・柱の根元・首のない騎士の石像・かがり火の台、灼熱の深層・霊廟・深淵は、それぞれの床の色に合う3つの物と、火を載せる物を1つ（鉄の火皿・燭台・灯籠。火は描かせない）。遺跡の物は色味を抑えさせ、洞窟と聖域にも使い回している。
- 床の落とし物（`floor_decals`。1536×1024を3×2のマスに分け、マスの中央に1つずつ）。「真上から見下ろした、床に平たく散らばっている物。瓦礫、古い骨（頭蓋骨は入れない）、折れた武器、割れた敷石、鎖と輪、壺のかけら。色味を抑えた灰色〜灰茶色。床そのもの・落ち影・血・発光は描かない」。
- 残響のかけら（`echo_shards`）。「左から小・中・大。小は細長い八面体が1本で水色、中は太めの1本と小さな1本で緑、大は3本の束で金色。面ごとに明暗をはっきり分け、いちばん明るい面に白いハイライトを1つ。ゲームでは高さ16〜30pxに縮めて暗い床にたくさん散らばるので、形は太く、色ははっきり。台座・にじみ・きらめき・影は描かない」。
- ボスの陣（`boss_sigil`。1024×1024）。この1枚だけ背景を真っ黒にさせた（ツールが絵の明るさをアルファにして白い絵にし、ゲームが色と動きを付ける）。「真上から見た円い陣。白〜明るい灰色の線だけで、面を塗らない。外から、太い二重の円、外を向いた棘が16本並ぶ輪、1か所が欠けた細い円、中央に縦に長い四芒星と4本の短い刃。線は石に刻んだ溝のように太さが揺らぐ。文字・読める記号・目・顔・髑髏は描かない」。
- 強化のカードの表と裏（`cards`。1536×1024を左右に2等分）。「2枚とも同じ外形で、幅と高さの比は2:3、角は少し丸い。表は青銅とくすんだ金の太い枠、内側は暗い石墨色の面で何も描かない。上から約28%の中央に丸い青銅の輪の台座（輪の中は暗いくぼみ。ゲームが紋章を重ねる）、そのすぐ下に左右へ伸びる細い金の飾り線、下の辺の中央に小さな四芒星。裏は同じ枠に深い藍色の面と放射状の線の地紋、中央に、1か所が欠けた輪が囲む縦に長い四芒星の金の浮き彫り。文字と数字は描かない」。輪の中心は、できた絵で測って `AbilityCard.RING` に入れた。

## 攻撃のエフェクトの素材（2026-11-24）

攻撃のエフェクトを、1枚絵の拡大とフェードから、素材の絵をシェーダーで動かす形に作り替えたときに、Codexの組み込み画像生成で4枚を作った（`codex exec` を4本並べて実行。どれも1回目の絵を採用した。大きさは指定と違うものがあったが、`python tools/build_vfx_art.py` が切り詰めて縮める）。元絵は `art/effects/vfx/source/` にある。

- どの依頼にも付けた条件。参考として、当時の戦闘の画面2枚とカードの画面（そろえたい品質の基準）、それまでのエフェクトの絵4枚（塗りの見本）を渡した。「完成した1枚のエフェクトではなく、ゲーム側のシェーダーが動かすための素材。背景は真っ黒で平ら。白〜灰色だけで描き、明るさだけが意味を持つ（いちばん熱い所・鋭い所は純白）。厚塗りの筆の跡で、太くはっきりした形。ぼかしただけのにじみ・レンズフレア・写真のような煙は描かない（にじみはゲーム側で足す）。数pxの大きさの違いと黒のむらは作り直しの理由にしない」と伝えた。
- 斬撃の軌跡（`slash_trail`）。「剣を振った軌跡を、まっすぐに伸ばした横長の帯として描く（弧に曲げない）。右端が先頭で、いちばん明るく鋭く、刃先のように斜めに切れている。左へ行くほど暗く細くなり、左の3分の1では何本もの筋にほつれて黒に消える。上の縁が刃の外側で、純白の細い芯が走るくっきりした線。下の縁は、筆を払ったように斜め後ろへ流れて柔らかく消える。帯の中に、帯と平行な筆の筋。先頭の近くに小さな光の欠片を数個」。
- 稲妻の帯（`bolt_strip`）。「画像を縦に3等分し、各段に稲妻を1本。どの稲妻も、段の左端の縦の中央から入り、右端の縦の中央へ抜ける。鋭い角でぎざぎざに折れ、芯は純白で太め、両脇に灰色の細い縁取り、2〜3か所に短い枝。3本は折れ方が違う」。
- 炎の帯（`flame_strip`）。「下端から炎が立ちのぼる。下端は一面に明るく、上へ行くほど炎の舌に分かれて、先がとがって黒に消える。左端と右端がつながる。大小の舌を12〜16本、高さはばらばら。舌の中に下から上への筆の筋。先からちぎれた小さな炎と火の粉を上に浮かべる」。
- 衝撃波の輪（`shock_ring`）。「真上から見た真円の輪。外の縁が衝撃の先頭で、いちばん明るく太い線だが、ところどころ欠けたり外へ跳ねたりしている。縁から内側へ、中心へ向かう放射状の筆の筋が伸びて黒に消える。中心のまわりは黒のまま。縁のすぐ外に、飛び散った小さな欠片」。

## エフェクトの元絵

- 元絵はCodexの組み込み画像生成で、番兵と主人公のベース画を画風の参考、従来のドット絵の連番を題材の参考として渡し、「最も強い瞬間の1枚。光は純黒の背景、煙は透過背景。約70pxで読める形」という共通の指示に種類ごとの説明を加えて作った。
- レベルアップの光の柱（`level_up.png`）はあとから足した。斬撃の元絵を画風の参考だけに渡し、「純黒の背景に、足元の楕円の光の輪から立ち上がり上へ細りながら消える金色の光の柱。小さな金と淡いクリーム色の光の粒と、上へ昇る細い光の筋。緑・紫・植物・地面・人物は描かない。周囲に広い黒の余白」と依頼した（治癒の元絵を参考に渡すと葉の形が混ざったため外した）。
