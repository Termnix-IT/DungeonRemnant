## ステータス画面の本の紙と革

ステータス画面の本（`HubStatus`）の紙と表紙の質感は、Codexの組み込み画像生成（gpt-image-2.5）で作りました（2026-11-14）。それまではシェーダーのノイズで描いていて、紙が平板に見えたためです。使う場所の参考に今のステータス画面のキャプチャを、画風の参考にロビーの背景（`art/hub/lobby_hall.png`）を渡しました。

3枚とも「横長1536×1024、真正面から見た平らな面が画面の端から端までを埋める。端・角・めくれ・折れ・綴じ目・本の形を描かない。光の勾配・周辺減光・落ち影・ハイライトの帯を描かず、明るさを全体で均一にする。文字・記号・模様・挿絵・印・枠・罫線・人物・物を描かない。大きな破れ・穴・濃い大きなしみ・輪じみ・焦げ・強い皺の影を描かない。写真ではなく手描きで塗った質感で、1ページが約670×660pxで表示される大きさで繊維や粒が潰れず、うるさくならない細かさ」という共通の指示に、次の違いを足しています。縁の焼け・のどの影・ページの影はゲーム側（シェーダー）で足すので、絵には入れさせていません。

- 紙A（`art/ui/source/grimoire/paper_a.png`、採用）：古い羊皮紙。明るい生成り〜淡い黄土色、ごく細かい繊維と毛穴の粒、雲のように大きくゆるやかな色むら、ごく薄い小さな斑点。
- 紙B（`paper_b.png`、別案）：手すきの古い紙。簀の目のようなごく淡い横の筋と細かい繊維。Aより均一で静か。
- 革（`leather_a.png`）：暗い赤茶のなめし革。細かいシボと、ごく細い擦れや細かなひび。型押し・金箔・鋲・縫い目・金具は描かない。

3枚とも指定どおりの大きさ（1536×1024）で、端や文字のない平らな面として返ってきました。紙Aは左上がわずかに暗く返ってきましたが、加工で光のむらを取るため表示には出ません。実際の画面でAとBを並べ、Bは横の筋が目録の点線や細い文字の後ろでちらつくため、雲のようなむらだけのAを採用しました。Bは元絵を残しています。

`python tools/build_grimoire_art.py` が、元絵から光のむらを取り、灰色の濃淡だけにして、平均を中間の灰色・濃淡の幅を一定にそろえ、`art/ui/grimoire/paper.png`（見開きに1枚で敷く）と `leather.png`（鏡映しで繰り返す）を書き出します。色は絵から取らず、シェーダーが共通Themeの `Grimoire` の紙の暗い色と明るい色（表紙も同じ）の間を、この濃淡で混ぜます。絵を差し替えても、文字と紙の明るさの比が検査で守られるようにするためです。
